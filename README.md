# Anonymous Complaint Box

A web-based Anonymous Complaint Management System designed to provide a secure and private platform for submitting, tracking, and managing complaints without revealing the complainant's identity.

## About the Project

Anonymous Complaint Box helps users submit complaints without storing their personal identity. Each complaint is assigned a unique Complaint ID, which allows users to track the status of their complaint.

The system also provides an admin dashboard for managing, monitoring, categorizing, and responding to complaints securely.

## Key Features

- Anonymous complaint submission
- Unique Complaint ID for tracking
- Complaint categorization
- Priority assignment
- Complaint status tracking
- Secure user-admin communication
- Admin dashboard
- Complaint management and monitoring
- Secure data handling

## Technology Stack

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## System Roles

### User
- Submit complaints anonymously
- Receive a unique Complaint ID
- Track complaint status
- Communicate securely with the administrator

### Admin
- View and manage complaints
- Categorize complaints
- Assign priority levels
- Update complaint status
- Monitor and manage complaints through the dashboard

## Project Objective

The main objective of this project is to provide a secure and anonymous platform where users can report complaints without fear of identity exposure, while allowing administrators to efficiently manage and track complaints.
